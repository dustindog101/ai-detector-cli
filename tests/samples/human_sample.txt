Hey guys, honestly I dont think switching to NoSQL makes sense here. When we tried using MongoDB for our web dev project last term, it seemed really convenient at first, but as soon as our data relationships got messy with user profiles and order histories we spent days fixing schema errors that PostgreSQL would have prevented automatically. And our professor mentioned in lecture that ACID compliance is pretty much mandatory for any transaction data anyway. So Id stick with a standard relational database for this system.
